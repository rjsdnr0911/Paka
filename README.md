# 🦖 공룡 게임 (Dino Game) - Python 버전

Chrome 오프라인 공룡 게임을 Python Pygame으로 재현하고 크게 개선한 버전입니다.

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python&logoColor=white)
![Pygame](https://img.shields.io/badge/Pygame-2.5.0+-green?logo=python&logoColor=white)
![Version](https://img.shields.io/badge/version-2.0--python-orange)

## ✨ 주요 기능

### 🎮 게임플레이
- ✅ **공룡 캐릭터** - 디테일한 픽셀아트 스타일의 공룡 (머리, 몸통, 팔, 다리, 꼬리)
- ✅ **점프 & 숙이기** - 스페이스바/위 화살표로 점프, 아래 화살표로 숙이기
- ✅ **5가지 선인장 타입** - Single, Double, Triple, Tall, Small
- ✅ **날아다니는 새** - 높이가 다른 두 가지 패턴, 날개 애니메이션
- ✅ **콤보 시스템** - 연속 회피 시 콤보 증가, 5콤보마다 파티클 효과
- ✅ **일시정지** - ESC 또는 P 키로 게임 일시정지

### 🎨 비주얼 효과
- 🌟 **파티클 시스템** - 달리기 먼지, 점프 효과, 콤보 파티클
- 🌄 **다층 배경** - 산, 구름, 해/달이 있는 역동적인 배경
- 🌙 **낮/밤 모드** - 100점마다 자동 전환되는 낮과 밤
- ⭐ **반짝이는 별** - 밤 모드에서 반짝이는 50개의 별
- 🌅 **회전하는 태양** - 햇살이 회전하는 애니메이션

### 💎 UI/UX
- 📊 **실시간 점수** - 현재 점수와 최고 점수 표시
- 🏆 **최고 점수 저장** - JSON 파일에 자동 저장
- 🎯 **콤보 카운터** - 화면에 실시간 콤보 표시
- 🎭 **부드러운 애니메이션** - 60 FPS 고정 프레임
- 🖥️ **크로스 플랫폼** - Windows, Mac, Linux 지원

### 🚀 성능 최적화
- ⚡ **60 FPS** - 고정 프레임레이트
- 🧹 **메모리 관리** - 효율적인 객체 관리
- 🎯 **정확한 충돌 감지** - Rect 기반 충돌 시스템
- 📊 **부드러운 난이도 곡선** - 점수에 따라 자동 속도 증가

## 🚀 설치 및 실행

### 필수 요구사항
- Python 3.8 이상
- pip (Python 패키지 관리자)

### 1. 레포지토리 클론
```bash
git clone https://github.com/rjsdnr0911/Paka.git
cd Paka
```

### 2. 의존성 설치
```bash
pip install -r requirements.txt
```

또는 직접 pygame 설치:
```bash
pip install pygame
```

### 3. 게임 실행
```bash
python dino_game.py
```

또는 실행 권한 부여 후:
```bash
chmod +x dino_game.py
./dino_game.py
```

## 🎮 게임 규칙

1. **목표**: 장애물을 피하면서 최대한 오래 생존하기
2. **점수**: 시간이 지날수록 자동으로 증가 (60프레임 = 1점)
3. **난이도**: 200점마다 게임 속도 증가, 장애물 생성 간격 감소
4. **콤보**: 장애물을 연속으로 회피하면 콤보가 쌓임, 5콤보마다 황금 파티클
5. **낮/밤**: 100점마다 낮과 밤이 자동 전환
6. **새 등장**: 점수가 높을수록 새가 등장할 확률 증가 (최대 30%)

## 🎯 게임 특징 상세

### 장애물 시스템
- **5종류의 선인장**: Single, Double, Triple, Tall, Small - 각기 다른 크기와 패턴
- **날아다니는 새**: 두 가지 높이(60px, 100px), 날개 펄럭이는 애니메이션
- **스마트 스폰**: 점수에 따라 새 등장 확률 증가 (`score / 5000`, 최대 30%)
- **충돌 감지**: 여유 있는 히트박스로 공정한 게임플레이

### 파티클 시스템
- **달리기 먼지**: 70% 확률로 매 프레임마다 생성
- **점프 먼지**: 점프 시 5개의 먼지 파티클
- **콤보 파티클**: 5콤보마다 10개의 황금색 파티클
- **물리 시뮬레이션**: 각 파티클은 독립적인 속도와 감쇠율

### 배경 시스템
- **산**: 5개의 산, 패럴랙스 효과 (속도 0.1x)
- **구름**: 5개의 구름, 각기 다른 속도 (0.6x)
- **해/달**: 낮에는 회전하는 8개 햇살, 밤에는 크레이터 2개
- **별**: 50개의 별, 삼각함수로 반짝임 효과
- **낮/밤 전환**: 배경색, 구름색, 바닥색 모두 변경

### 콤보 시스템
- 장애물을 통과할 때마다 콤보 +1
- 5콤보마다 황금 파티클 효과
- 게임오버 시 최대 콤보 표시
- 실시간 화면 왼쪽 상단에 표시
