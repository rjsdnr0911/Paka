# 🦖 공룡 게임 (Dino Game)

Chrome 오프라인 공룡 게임을 재현하고 크게 개선한 웹 게임입니다.

## ✨ 주요 기능

### 🎮 게임플레이
- ✅ **공룡 캐릭터** - 디테일한 픽셀아트 스타일의 공룡
- ✅ **점프 & 숙이기** - 스페이스바/위 화살표로 점프, 아래 화살표로 숙이기
- ✅ **5가지 선인장 타입** - Single, Double, Triple, Tall, Small
- ✅ **날아다니는 새** - 높이가 다른 두 가지 패턴
- ✅ **콤보 시스템** - 연속 회피 시 콤보 점수와 파티클 효과
- ✅ **일시정지** - ESC 또는 P 키로 게임 일시정지

### 🎨 비주얼 효과
- 🌟 **파티클 시스템** - 달리기 먼지, 점프 효과, 콤보 파티클
- 🌄 **다층 배경** - 산, 구름, 해/달이 있는 역동적인 배경
- 🌙 **낮/밤 모드** - 100점마다 자동 전환되는 낮과 밤
- ⭐ **반짝이는 별** - 밤 모드에서 반짝이는 별들
- 🌅 **회전하는 태양** - 햇살이 회전하는 애니메이션

### 💎 UI/UX
- 📱 **완전한 반응형** - 모바일, 태블릿, 데스크톱 지원
- 👆 **터치 제스처** - 스와이프로 점프/숙이기
- 🎯 **모던 디자인** - 그라디언트와 글래스모피즘 효과
- 🏆 **최고 점수 저장** - 로컬 스토리지에 자동 저장
- 🎭 **부드러운 애니메이션** - 모든 UI 요소에 부드러운 전환 효과

### 🚀 성능 최적화
- ⚡ **60 FPS** - requestAnimationFrame 사용
- 🧹 **메모리 관리** - 화면 밖 객체 자동 제거
- 🎯 **정확한 충돌 감지** - 히트박스 기반 충돌 시스템
- 📊 **부드러운 난이도 곡선** - 점수에 따라 자동 속도 증가

## 🎯 조작법

| 키 | 동작 |
|---|---|
| `스페이스바` 또는 `↑` | 점프 |
| `↓` | 숙이기 |
| `ESC` 또는 `P` | 일시정지/재개 |
| `클릭/터치` | 점프 (게임 중) |
| `스와이프 ↑` | 점프 (모바일) |
| `스와이프 ↓` | 숙이기 (모바일) |

## 🎮 게임 규칙

1. **목표**: 장애물을 피하면서 최대한 오래 생존하기
2. **점수**: 시간이 지날수록 자동으로 증가
3. **난이도**: 200점마다 게임 속도가 증가하고 장애물이 더 자주 등장
4. **콤보**: 장애물을 연속으로 회피하면 콤보가 쌓이고, 5콤보마다 특수 효과
5. **낮/밤**: 100점마다 낮과 밤이 전환됨

## 🎯 게임 특징 상세

### 장애물 시스템
- **5종류의 선인장**: Single, Double, Triple, Tall, Small
- **날아다니는 새**: 두 가지 높이로 랜덤 생성
- **스마트 스폰**: 점수에 따라 새 등장 확률 증가 (최대 30%)

### 파티클 시스템
- 달리기 중 발 밑에서 먼지 생성
- 점프 시 5개의 먼지 파티클
- 5콤보마다 황금색 파티클 폭발 (10개)

### 배경 시스템
- **산**: 3가지 레이어로 패럴랙스 효과
- **구름**: 5개의 구름이 각기 다른 속도로 이동
- **해/달**: 낮에는 회전하는 햇살, 밤에는 크레이터가 있는 달
- **별**: 50개의 별이 반짝이는 애니메이션
