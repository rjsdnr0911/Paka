# 🦖 공룡 게임 (Dino Game)

구글 Chrome 오프라인 공룡 게임을 재현한 웹 게임입니다.

## 기능

### 1차 구현 완료 기능
- ✅ 공룡 캐릭터
- ✅ 점프 기능 (스페이스바, 위 화살표)
- ✅ 숙이기 기능 (아래 화살표)
- ✅ 장애물 (선인장) 자동 생성
- ✅ 충돌 감지
- ✅ 점수 시스템
- ✅ 최고 점수 저장 (로컬 스토리지)
- ✅ 게임 속도 자동 증가
- ✅ 게임 오버 및 재시작
- ✅ 반응형 디자인
- ✅ 모바일 터치 지원

## 조작법

- **스페이스바** 또는 **위 화살표**: 점프
- **아래 화살표**: 숙이기
- **클릭/터치**: 점프 (모바일)

## 실행 방법

1. `index.html` 파일을 브라우저에서 열기
2. 스페이스바를 눌러 게임 시작
3. 장애물을 피하면서 최고 점수 달성!

## 파일 구조

```
├── index.html      # 메인 HTML 파일
├── style.css       # 스타일시트
├── game.js         # 게임 로직
└── README.md       # 프로젝트 설명
```

## 게임 특징

- **자동 난이도 증가**: 점수가 올라갈수록 게임 속도가 빨라집니다
- **다양한 장애물**: 큰 선인장과 작은 선인장이 랜덤으로 생성됩니다
- **최고 점수 기록**: 브라우저의 로컬 스토리지에 최고 점수가 자동 저장됩니다
- **부드러운 애니메이션**: Canvas API를 사용한 부드러운 게임 플레이
